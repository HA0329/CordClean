## 缺陷修复

### D1：AI 顾问空输出/截断不重试

- 现象：真实模型偶发只返回思维链/空内容；低 `maxTokens` 切换推理模型时输出被截断，直接报 `INVALID_RESPONSE`，用户需手动重试或调 token。
- 修复：`analyze` 对 `INVALID_RESPONSE`（空内容/非法 JSON/截断）自动重试一次，并把 `maxTokens` 提升到至少 16384（按模型上限收敛）；两轮仍失败才报错，截断提示保留。
- 真实复验：空补充说明连续 3/3 成功；deepseek-v4-pro 在低 maxTokens 下自动重试后成功。

### D2：AI 顾问并发提交不取消旧分析

- 现象：并发/重复调用 `analyze` 时两次请求同时进行，可能互相覆盖缓存、浪费 token。
- 修复：新的分析开始前 abort 上一次请求；旧请求以 `CANCELLED` 结束，新请求正常返回。
- 真实复验：第一次 `CANCELLED`、第二次成功。

## 兼容性与升级注意

- 无数据/设置/插件格式破坏性变更，可直接覆盖升级；
- AI 分析在空输出/截断时会自动重试一次（会多一次模型请求，仅在失败时发生）；
- 并发提交分析时旧请求会被取消（与工坊生成行为一致）；
- 未配置 API Key 时 AI 仍明确不可用，无离线绕过。

## 已知限制

- 真实 provider 无法强制 429，限流分类用本地真实 HTTP 429 验证；
- 工坊 `maxTokens` 下限 32768，真实输出截断分支难以稳定触发（截断/重试由单测覆盖）；
- AI 输出语义仍依赖模型；生成插件“可运行”验证到安装/启用/真实扫描/卸载，不等同于对所有生成变体穷举冒烟。
