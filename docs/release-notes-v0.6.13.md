# CordClean v0.6.13 发布说明

**发布日期：2026-11-23** · 前置版本：v0.6.12

本次为补丁版本：补齐 v0.6.12 发布前缺失的「真实不可控用户使用 + 临时 Key 真调模型」验收，并修正一处真实测试中发现的配置文案问题。**无破坏性变更，不修改既有数据/设置/安全限制。**

## 本次改动

### 真实模型全链路验证（AI 清理顾问 + AI 插件工坊）

使用临时 API Key（仅环境变量传入，未写入仓库/文档/日志/截图）真实调用 `api.deepseek.com`：

- AI 顾问：probe 连通、真实分析、错误 Key（AUTH）、断网（NETWORK）、取消（CANCELLED）、
  请求级截断（max_tokens=4 → finish_reason=length）、低 token 边界（2049）、不支持视觉的模型 + 图片明确报错；
- AI 工坊：真实生成 v2 插件包 → `inspectPackage` 零错误 → `installPackage` 成功 → 启用并注册任务 →
  真实扫描 TEMP（命中 14 个 >1MB 文件、0 错误）→ `uninstallPackage` 后消失；空需求/非法模型给出可读错误；
- **结果：16 / 16 通过**。记录与复现脚本见
  [真实用户模拟与真实模型验证记录](verification/v0.6.13-real-user-simulation.md)、`scripts/ai-live-verify.ts`。

### 真实用户场景矩阵

新增 `scripts/user-sim-matrix.ts`，覆盖：首次使用（空数据目录）、空数据扫描、未扫描/非法 itemId、
未知 taskId、扫描取消、并发扫描/扫描中清理、无权限路径、长路径（307 字符）、空格/中文文件名、
大目录（3000 文件）、隔离 fixture 预演+真实清理、设置越界 clamp、未配置 Key 的 AI/工坊明确不可用、
工坊超长需求、重启恢复（设置/插件状态/历史）。

- **结果：15 / 15 通过**；全部在临时数据目录内，未触碰真实用户文件。

### 缺陷修复

- AI 顾问与工坊的 `maxTokens` 配置说明补充语义：**小于等于 2048 的值会被自动提升为 65536**
  （避免 JSON/代码输出被截断）。真实测试确认该行为存在但文案未说明，属误导；本次仅修正文案，
  不改变既有行为与安全边界。

### 验证资产

- `scripts/ai-live-verify.ts`：真实模型全链路验证（Key 仅从 `AI_KEY` 环境变量读取，不落盘）；
- `scripts/user-sim-matrix.ts`：真实用户不可控场景矩阵；
- `docs/verification/v0.6.13-real-user-simulation.md`：矩阵结果、发现与安全隔离说明。

## 验证结果

- `pnpm typecheck` / `pnpm typecheck:ui`：通过；
- `pnpm test`：**106 个测试文件 / 931 个用例通过**；
- `pnpm build`：通过；
- `pnpm docs:check`：通过（12 插件 / 38 任务 / 73 RPC / 106 文件 / 931 用例 / 385 规则）；
- `node scripts/e2e-ui.mjs`：7 页面 + 侧边栏 + 扫描全链路通过；
- 真实模型：16/16；真实用户场景矩阵：15/15。

## 兼容性与升级注意

- 无数据/设置/插件状态/安全限制变更；可直接覆盖升级；
- 新增验证脚本只读/隔离运行，不参与默认启动，不影响应用体积与行为。

## 已知限制

- 真实模型验证依赖临时 Key 与外网；仓库内脚本需要自行设置 `AI_KEY`（不会内置 Key）；
- 生成插件的「可运行」验证到安装/启用/真实扫描/卸载，未覆盖所有模型输出变体的运行时冒烟；
- 本机系统较干净，部分检测类插件真实命中为 0（能力由注入式单测覆盖）。
