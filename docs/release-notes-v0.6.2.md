# CordClean v0.6.2 发布说明

**发布日期：2026-10-26** · 前置版本：v0.6.1

本次更新是日志系统 Phase 2：完成**结构化 JSONL、运行时日志配置、实时 tail、RPC requestId 关联**，并补齐界面日志查看器与性能基准。

## 重点更新

### 结构化 JSONL 日志

- 统一日志文件改为 **JSONL**：每行一个 `LogEntry`（`ts / level / scope / message / fields / requestId / pluginId`）；
- 旧版纯文本日志行在读取时自动包装为 `legacy` 条目，历史日志不丢；
- 写入/读取/实时事件共用同一数据结构，界面可直接按级别、来源、字段筛选；
- 脱敏、字段截断、数组/深度限制在写入层统一处理。

### 运行时日志配置

- 设置新增 `logging`：级别、单文件上限、轮转保留份数、旧日志保留天数；
- 设置页「日志设置」可即时修改并生效（settings 变更 → core logger 重新应用），无需重启；
- 环境变量 `CORDCLEAN_LOG` 仍可覆盖级别。

### 实时 tail

- 新增 `onLogEvent` 事件总线：Web 服务端通过 WebSocket `log` 事件、Electron 主进程通过 IPC `log` 事件实时推送；
- 日志查看器新增「实时」开关，打开后无需轮询即可看到新日志；
- 依旧保留自动刷新/暂停/筛选/搜索/复制/打开目录。

### RPC 关联与降噪

- 每次 RPC 生成 `requestId`（`rpc-N`），失败/慢请求日志带该 ID，可与界面操作对应；
- 继续沿用 Phase 1 降噪策略：高频只读成功不记，失败/慢请求/业务方法记录，参数摘要化。

## 验证

- 自动化测试：**65 个测试文件 / 471 个用例全部通过**（新增 JSONL、实时总线、运行时级别、requestId 用例）；
- `tsc` / `vue-tsc` 0 错误；`pnpm build` 成功；
- `pnpm bench:logging`：JSONL 缓冲写入约 **205,000 行/秒（35.5 MB/秒）**，读取 1000 条约 12.7 ms；
- 文档：[日志系统设计](logging.md)、[日志基准](benchmark-logging.md)。

## 兼容与升级

- 日志目录/旧日志保留策略不变，旧文本日志可继续查看；
- 新增设置字段缺省时自动使用默认值（info / 5MB / 保留 2 份 / 14 天）；
- `app/logs/recent` 保持可读文本兼容；新增 `app/logs/entries` 供新界面使用。

## 已知限制

- 暂无同 scope 重复日志合并/节流；
- 暂不支持按插件单独设置日志级别；
- 日志上传/远程诊断尚未提供。
