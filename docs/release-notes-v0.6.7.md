# CordClean v0.6.7 发布说明

**发布日期：2026-10-31** · 前置版本：v0.6.6

本次更新完成两件体验增强：**用户临时目录（%TEMP%）逐文件拆分**与**任务级批量操作**。

## 重点更新

### %TEMP% 逐条上报

- `rule:system_temp` 中整个 `%TEMP%` 目录不再作为单个清理项；
- 改为扫描其**顶层条目**（文件/目录）逐条上报，每条可单独勾选；
- 所有临时条目默认不勾选，并提示“可能正被程序占用，确认后再选择”；
- 单条目录会计算大小，文件显示实际大小；
- 自动跳过 CordClean 自身数据目录（便携/测试场景数据目录可能位于 TEMP 下）；
- 实测：`rule:system_temp` 扫描返回 307 条顶层条目，根目录项不再出现，条目 `recommended=false / defaultSelected=false`。

> 空目录原本就是「一个空目录一条项」，本次保持逐目录上报；默认不勾选策略沿用 v0.6.5。

### 任务级批量操作

清理能力区新增：

- **分类三态复选框**：可整类全选/取消该分类下所有任务（含部分选中态）；
- **全选任务 / 反选**：一次选择或反转全部任务；
- **扫描选中任务**：明确只扫描当前勾选任务，不必回到右上角按钮；
- 配合任务搜索/风险筛选，筛选后的任务可批量操作；
- 任务列表仍限高 460px 滚动，避免 38 张卡片撑满页面。

## 验证

- 全量测试：**65 个测试文件 / 475 个用例通过**；
- `tsc` / `vue-tsc` 0 错误；`pnpm build` 成功；
- 后端复核：`rule:system_temp` 扫描 → 307 条逐项结果、根 `%TEMP%` 项消失、临时条目默认不推荐/不勾选；
- Web 走查：任务搜索/风险筛选、分类复选框、全选/反选、扫描选中任务均可用；列表滚动高度 460px。

## 兼容与升级

- 规则文件不变，仅 `rule-pack` 对 `%TEMP%` 特殊目标的拆分行为变化；
- 旧扫描结果中的整体 `%TEMP%` 项在重新扫描后消失；已选中的旧 itemId 不会影响新结果；
- 删除仍经过同一路径策略、确认与清理引擎。

## 已知限制

- `%TEMP%` 顶层目录仍按目录整体删除（不递归拆成内部文件）；如需要更深层拆分，可后续增加；
- 临时条目没有按时间过滤（例如只清 7 天前），目前依赖用户逐项选择；
- 任务级批量操作只影响「扫描哪些任务」，不直接批量勾选某任务的结果项（结果页已有分组三态勾选）。
