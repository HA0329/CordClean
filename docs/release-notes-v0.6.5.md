# CordClean v0.6.5 发布说明

**发布日期：2026-10-31** · 前置版本：v0.6.4

本次更新修复真实用户走查发现的核心（P1）体验问题：结果选择入口、撤销状态、预演后继续、默认推荐策略。

## 重点更新

### P1-1 扫描结果自动定位

- 从扫描结果页点击「去选择可清理项」后，清理页会自动滚动到结果区（实测 `scrollTop` 从 0 → 1997）；
- 步骤条改为状态驱动：未扫描时高亮「扫描」，有结果后高亮「选择」，清理中高亮「清理」；
- 不再让用户停留在 38 张任务卡片顶部找不到结果。

### P1-2 撤销状态如实展示

- 历史页「撤销上次清理」改为根据 `clean/undo-state.available` 启用/禁用；
- 不可撤销时显示「暂无隔离项可撤销」；点击时明确告知“回收站记录请在 Windows 回收站手动还原”；
- 历史任务列从内部 id（如 `empty-dirs`）改为用户可读名称（如「空目录」）。

### P1-3 预演后继续实际清理保留选择

- 预演完成页按钮改为「继续实际清理」；
- 点击后回到清理页，保留预演时的 itemIds、关闭预演模式并直接弹出实际清理确认；
- 实测确认框正确显示「即将清理 1 项」，不再重置为推荐集合的 181 项。

### P1-4 默认推荐策略更保守

- 空目录（0 B）不再默认勾选、不进入一键推荐（`recommended=false`），避免改变用户目录结构；
- 整个 `%TEMP%` 目录作为一个清理项时标记为“不推荐”，并提示可能影响正在运行的程序；用户需显式勾选；
- 清理项 `defaultSelected` 与 `recommended` 语义对齐，界面「只选安全项」改为「只选推荐项」。

## 验证

- 全量测试：**65 个测试文件 / 475 个用例通过**；
- `tsc` / `vue-tsc` 0 错误；`pnpm build` 成功；
- 真实走查复核：
  - 「去选择」后结果区可见（自动滚动）；
  - 预演后继续实际清理 → 确认框保留 1 项；
  - 实际清理后历史页撤销按钮禁用，任务显示「空目录」；
  - 扫描结果中空目录 138 项“推荐 0”；整体 `%TEMP%` 推荐/默认勾选均为 false（RPC 复核）。

## 兼容与升级

- 新增 `recommended` 字段为可选，旧数据/外部插件不受影响；
- 不改变删除引擎、安全策略与规则格式；
- 空目录/整体临时目录仍可在结果页手动勾选清理。

## 已知限制

- `%TEMP%` 仍是整体一项（未拆成逐文件扫描），只是不再默认勾选；后续可做逐项/按天过滤；
- 真实走查中的 P2 问题（任务卡过长、数字对账、Web Electron Node 标签等）本次未全部处理。
