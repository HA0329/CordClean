# CordClean v0.6.6 发布说明

**发布日期：2026-10-31** · 前置版本：v0.6.5

本次更新处理真实用户走查中的 P2 体验问题：数字对账、Web 外壳信息、任务查找、历史明细、AI 配置入口与日志时间。

## 重点更新

### P2-2 扫描结果数字对账

- 结果区新增一句对账说明，把数字关系直接写出来：
  `扫描发现 N 项（体积） = 可清理 N 项 + 受保护 N 项；可清理中默认推荐 N 项，需确认 N 项`；
- 实测：`扫描发现 255 项（1.6 GB）：可清理 250 项（1 GB）+ 受保护 5 项（614.2 MB）；默认推荐 51 项（676.9 MB），需确认 1 项（231 MB）`。

### P2-3 Web 外壳不再误显示 Electron Node

- “Electron Node”信息行仅在桌面外壳且有 Electron 版本时显示；
- Web 外壳只显示系统 Node / 当前运行时，避免错误信息。

### P2-4 任务列表可搜索、可筛选、限高滚动

- 清理能力区新增任务搜索（名称/说明/id）与风险筛选；
- 任务列表限高 460px 滚动，不再让 38 张卡片把页面撑得过长；
- 实测搜索「微信」显示 `1 / 38 个任务`，结果只保留匹配任务。

### P2-5 历史记录可展开明细

- 清理历史每行支持展开：模式（预演/实际清理）、回收站、隔离区、外部消失、条件跳过、失败数；
- 配合 v0.6.5 的撤销状态与可读任务名，历史页信息更完整。

### P2-6 未配置 API Key 的入口

- AI 清理顾问状态栏新增「填写 API Key」按钮，点击滚动并聚焦到 Key 输入框；
- 「开始分析」在未配置时带禁用原因提示（title）。

### P2-7 日志查看器带日期

- 日志行时间从 `HH:mm:ss` 改为 `MM-DD HH:mm:ss`（本地时区），跨天排查不再混淆；
- 概览数据目录按钮保留完整路径 title（设置页显示完整路径）。

## 验证

- 全量测试：**65 个测试文件 / 475 个用例通过**；
- `tsc` / `vue-tsc` 0 错误；`pnpm build` 成功；
- Web 走查复核：无 Electron Node 行；任务搜索「微信」→ 1/38；任务列表最大高度 460px；结果对账文案与数字正常；「去选择」自动定位结果区。

## 兼容与升级

- 仅界面与展示逻辑调整，不改变扫描/清理引擎、规则或默认安全策略；
- P2-1（步骤条状态）已在 v0.6.5 一并修复。

## 已知限制

- 空目录仍默认不勾选、整体 `%TEMP%` 仍是单项（只是不默认推荐）；
- 任务选择仍以「卡片勾选 + 全局扫描」为主，尚未做任务级批量操作菜单。
