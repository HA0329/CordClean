## 3. 发现与处理

| 发现 | 处理 |
| --- | --- |
| 真实测试发现：AI 设置里 `maxTokens ≤ 2048` 会被静默提升到 65536（避免 JSON/代码截断），但配置文案未说明 | **已修**：AI 顾问与工坊的 `maxTokens` 配置说明补充该语义；无功能回退 |
| 矩阵首轮 S7/S9 失败为验证脚本自身问题（自定义任务未走默认清理/未用长路径 API），非产品缺陷 | 修正脚本后 15/15 通过 |
| 未发现 AI 全链路功能缺陷；真实模型下生成包可通过宿主校验、安装、运行、卸载 | 无需业务代码修复 |

## 4. 安全与隔离

- Key：仅 shell 环境变量传入；脚本不打印 Key；仓库/文档/截图无 Key；
- 数据：临时 dataDir + 临时 fixture，插件安装/清理均在隔离目录；生成插件在临时数据目录安装后即卸载；
- 真实本机数据：未清理任何真实用户文件；AI 分析仅读取脱敏画像与只读扫描上下文。
